# 🚢 MINI PROYECTO: Batalla Naval

## 📝 Descripción del Juego

Batalla Naval es un juego estratégico por turnos desarrollado como mini-proyecto académico para la **Universidad del Valle**.  
El objetivo del juego es hundir la flota enemiga realizando disparos sobre un tablero, aplicando las reglas clásicas de Batalla Naval.

El proyecto fue desarrollado utilizando **Java y JavaFX**, implementando una **arquitectura Modelo–Vista–Controlador (MVC)** y representaciones gráficas mediante **figuras 2D nativas**, sin uso de imágenes para los elementos principales del juego.

---

## 🎮 Funcionalidades Principales

- Colocación de barcos por parte del jugador
- Disparos por turnos contra la máquina (IA)
- Resultados de disparo:
  - 🌊 Agua
  - 🎯 Impacto (Tocado)
  - 💥 Barco hundido
- Representación gráfica mediante figuras 2D (rectángulos, polígonos, líneas)
- Persistencia de partidas (guardar y cargar juego)
- Interacción mediante mouse y teclado
- Modo espía opcional
- Finalización del juego al hundir toda la flota enemiga

## 🎨 Gráficos 2D

Todos los elementos visuales del juego fueron implementados utilizando **figuras 2D nativas de JavaFX**, cumpliendo el requisito de no usar imágenes para:

- Barcos (rectángulos, polígonos y líneas)
- Disparos de agua
- Impactos
- Explosiones al hundir barcos

---

Persistencia de Datos

El estado del juego se guarda mediante **serialización**, permitiendo:
- Continuar partidas previamente iniciadas
- Recuperar el tablero, flotas y turnos
